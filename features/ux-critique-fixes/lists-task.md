# Lists worker: a truthful, readable Projects shell (stage A of the UX critique fixes)

## Goal

The Projects shell (rail, Projects page, project page, Triage, feature page) never claims an empty, failed or all-clear state while it loads; Triage's Needs you holds exactly the runs that wait on the operator, including a paused run that needs a decision and never a superseded one; Triage fills the desktop; stopped runs read as dates and days; badges carry their own state tone; the operator can pin a run to Triage; the run chip leads with the run's state.
