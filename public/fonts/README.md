# Fonts

Atkinson Hyperlegible Next and Atkinson Hyperlegible Mono by the Braille Institute of America, licensed under the SIL Open
Font License 1.1 (https://openfontlicense.org). The two files are the latin-subset variable-weight builds as Google Fonts
serves them (fetched 2026-10-09); `src/projects/theme.css` declares them for the Projects viewer, which never requests a
font from another host.
