## 2. GH7 reuse evidence

- **The field.** `workflow/checks.py` `reuse_packet` writes `reused_from: {path, sha256}` into `verification/candidate/<lane>/<n>/packet.json`, `path` the run-relative worker packet (`verification/worker/<lane>/<n>/packet.json`). The server already parsed it (`packetSchema.reused_from`, `LoadedPacket.reusedFrom`).
- **The retype** (`server/projects.ts` `retypeReuseEvents`, applied to `normalizeEvents`' output): the lane's gate row `candidate_<lane>` (`workflow/pipeline.py` logs it once per candidate attempt) is served `type: 'result_reused'`, `reused_from_attempt` = the worker packet's `<n>`, `result_uri` = `/api/projects/<p>/workflows/<w>/runs/<r>/results/<lane>/<n>`. Sequence, attempt, status, message, event count and `/events?after=` paging are unchanged.
- **Matching limits** (nothing is retyped otherwise): the candidate packet must load (hash and schema), carry `reused_from` naming the same lane's worker packet, be the only reused packet of the lane and the lane's lowest candidate attempt (the controller reuses only attempt 1, `reusable_packet`); the event is the lane's first `candidate_<lane>` row with a gate status (`passed`/`blocked`), and no `running` row of that lane may precede it (a checked attempt started before it). No message text is read. The worker packet `reused_from` names must itself be registered and loaded (phase `worker`, the same lane, the attempt `reused_from.path` names) and its registered `sha256` must equal `reused_from.sha256` (the digest `reuse_packet` took of its bytes): a reuse whose worker packet is not registered (`reuse-missing`) or is registered with other bytes (`reuse-hash`) retypes nothing.
- **Tests**: `server/projects.test.ts` `a reused candidate packet retypes its lane's gate event as result_reused, …` (one lane; several attempts; no reuse with a look-alike message; another lane's worker packet; reuse after a checked attempt; `reuse-missing` and `reuse-hash`, each with no `result_reused` and no `reused_from_attempt`, both red against 4f2778a; paging at every boundary). `:902` is narrowed by a comment: that run has no reuse.
